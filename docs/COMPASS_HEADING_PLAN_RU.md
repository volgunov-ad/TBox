# План: курс с магнитометра компаньона (RM3100 / MMC5983)

Абсолютный курс для DR-тени с модуля на ESP32-S3. Сейчас `MockHeadingSource` — только **относительный** курс: гиро ГУ, руль, гиро+руль. Компас даёт азимут относительно севера без спутников (тоннель, паркинг, старт после простоя).

**По умолчанию чип: RM3100 по I2C.** MMC5983 — второй вариант в том же меню. SPI для магнитометра не используем (шина занята MCP2515).

Связанные подсистемы: прошивка `firmware/esp32-companion/`, NDJSON v1, вкладка «Компаньон», `MockLocationJob` / `MockHeadingSource`, калибровки гиро/руля, geo-debug.

Внедрение **по фазам**. Фаза 1 (шина + меню + телеметрия) не меняет DR. Фазы 2–3 — калибровка и источники курса.

---

## 1. Цель продукта

1. Подключить к компаньону **один** 3-осевой магнитометр на I2C.
2. На вкладке **«Компаньон»** выбрать чип: **RM3100** (default) или **MMC5983**. Выбор живёт в NVS ESP, как baud UM980.
3. Стримить сырые µT и магнитный heading на ГУ.
4. После калибровки — новые пункты «Источник курса»: **Компас** и **Гиро+компас** (гиро как сейчас, компас — медленный абсолютный якорь).

Без модуля / при неверном чипе в меню поведение DR **как сейчас**.

`gps.course` UM980 — COG (куда едем), не heading (куда нос). Компас — про нос. На прямой при скорости они близки; на стопе, задней и в заносе — нет.

## 2. Железо

### 2.1 Пины (DevKitC-1)

| Функция | GPIO | Заметки |
|---------|------|---------|
| I2C SDA | **5** | не конфликтует с реле (GPIO 9) |
| I2C SCL | **6** | 400 кГц, подтяжки к 3.3 В (часто уже на модуле) |
| DRDY (опционально) | 16 | v1 можно не подключать: опрос STATUS |
| Питание модуля | 3.3 В | общий GND с DevKit |

SPI 11–14 (MCP2515), UART 17/18 (UM980), входы 1–4, реле 9/10 — не трогать.

Модуль **на кабеле 20–50 см**, не на плате ESP: токи LDO / UART / CAN портят поле. Крепление жёстко к кузову, ближе к продольной оси, далеко от динамиков, моторов, обогрева. Wi‑Fi/BT компаньона не включать.

### 2.2 RM3100 (default)

- Только **I2C**: `I2CEN = HIGH` (3.3 В). На дешёвых платах часто `I2CEN` сидит на GND (только SPI) — такие не брать.
- Адрес `0x20…0x23` (`SA0`/`SA1`). Скан 0x20–0x23, REVID ожидаем `0x22`.
- Cycle count по умолчанию **200**. В µT переводит прошивка (формула PNI от cycle count), ГУ всегда видит µT.
- SCL до 1 МГц по даташиту; у нас **400 кГц**.

### 2.3 MMC5983MA

- I2C адрес **0x30**, 3.3 В.
- 18 бит; SET/RESET катушки — в прошивке раз в 1–5 с (обнуление офсета чипа).
- В µT тоже на ESP.

Адреса RM3100 и MMC5983 **не пересекаются**. Обычно на шине один модуль. Скан обоих — только подсказка в UI («выбран RM3100 — нет; на шине MMC5983»).

Аксель на той же плате (tilt-compensation) — **не в v1**. v1: курс из горизонтальных X/Y, модуль ставить примерно в горизонте. Уклоны SUV — фаза later (аксель рядом или pitch/roll ГУ).

## 3. Выбор чипа (вкладка «Компаньон»)

Паттерн как **скорость UM980**: dropdown + статус, команда на ESP, значение в NVS компаньона. На ГУ **не** дублировать в DataStore — источник истины `hello`.

Размещение: сразу под baud UM980 (ещё до блока координат).

| Элемент | Поведение |
|---------|-----------|
| **Dropdown «Магнитометр»** | `RM3100` / `MMC5983`. Default **RM3100**, если в NVS пусто. Enabled = `controlsEnabled` (компаньон подключён, не OTA). |
| Статус «Компас» | Да / нет (`hello.mag` — выбранный чип отвечает) |
| Статус «Чип» | `rm3100` / `mmc5983` / `—` |
| Статус «На шине» | что нашли сканом (`rm3100`, `mmc5983`, оба, пусто) — чтобы поменять пункт, если default не совпал с железом |
| Курс / \|H\| | из последнего `t:mag` |

Смена пункта:

1. Host → `magChipSet` `{chip:"rm3100"|"mmc5983"}`.
2. ESP пишет NVS, останавливает текущий драйвер, init выбранного, скан шины.
3. Device → `magChip` `{chip, ok, mag, seen:[…]}` и обновлённый `hello`.
4. Нет выбранного чипа: `mag:false`, поток `t:mag` не идёт, DR-пункты компаса скрыты.

Прошивка без магнитометра в коде (старый fw): полей `mag*` в `hello` нет — dropdown disabled, подсказка «нужна прошивка 0.6+».

## 4. Протокол NDJSON v1

`v` остаётся `1`. Неизвестные поля старые клиенты игнорируют.

### 4.1 Device → Host: дополнение `hello`

| Поле | Смысл |
|------|--------|
| `mag` | `true`, если выбранный чип инициализирован и отвечает |
| `magChip` | `"rm3100"` \| `"mmc5983"` — **выбор** (NVS), даже если `mag:false` |
| `magSeen` | массив `"rm3100"` / `"mmc5983"`, что ответило на скане (может быть пустым) |

Нет ключа `mag` на старом fw → магнитометра в прошивке нет.

### 4.2 Device → Host: `t:mag` (~5–10 Гц)

Не смешивать с `gps` (1 Гц мало для DR 2 Гц; GPS не тормозить). Во время OTA / UM980 bridge — как `gps`, не слать. Heartbeat не глушить: опрос I2C в **отдельном task** (урок UM980 в main loop).

```text
{"v":1,"t":"mag",
 "chip":"rm3100",
 "hx":12.4,"hy":-3.1,"hz":41.2,
 "heading":217.3,
 "fs":48.2,
 "ok":true}
```

| Поле | Единицы | Смысл |
|------|---------|--------|
| `chip` | — | активный драйвер |
| `hx,hy,hz` | µT | сырые оси модуля (без hard-iron ГУ) |
| `heading` | ° | магнитный курс 0…360, atan2(hy, hx) в рамке модуля, без declination и без калибровки ГУ |
| `fs` | µT | \|H\| — детектор возмущения |
| `ok` | bool | измерение валидно (не насыщение, не таймаут I2C) |

Ориентация осей модуля → кузов: константа в прошивке или later команда; v1 — документ «X вперёд, Y влево, Z вверх» и перестановка в драйвере под конкретный breakout.

### 4.3 Host → Device / ack

| `t` | Направление | Поля |
|-----|-------------|------|
| `magChipSet` | H→D | `chip`: `"rm3100"` \| `"mmc5983"` |
| `magChip` | D→H | `chip`, `ok`, `mag`, `seen`[] |

Невалидный `chip` → `ok:false`, выбор не менять.

## 5. Прошивка (`firmware/esp32-companion/`)

Версия **0.6.0**. Новые файлы (без inline-хаоса в `main.c`):

| Файл | Роль |
|------|------|
| `mag.h` / `mag.c` | NVS, скан, выбор чипа, task, `protocol_send_mag` |
| `rm3100_i2c.c` | MagI2C: CMM, cycle count, REVID, чтение MX/MY/MZ |
| `mmc5983_i2c.c` | 18-bit, SET/RESET, product ID |

Шина: `i2c_master` IDF 5.x, порт 0, GPIO 5/6, 400 кГц.

NVS namespace `mag`, ключ `chip` (`int`: 0=rm3100, 1=mmc5983). Пусто → **RM3100**.

Старт: `nvs_load` → probe selected → если ок, task 50 Гц sample / 10 Гц JSON. Скан обоих адресов для `magSeen` — на init и после `magChipSet`.

`hello` собирает `protocol_set_mag_for_hello(...)` по аналогии с `protocol_set_can_for_hello`.

Smoke без железа: сканер не находит чип, `hello.mag=false`, `magChip=rm3100` — USB-тесты не краснеют.

## 7. Калибровка (фаза 2)

Калибровка — свойство **машины + крепления**, хранить на ГУ (`Settings` / DataStore), не в NVS ESP. Смена модуля или перестановка → пройти заново.

Окно «Калибровка компаса» рядом с гиро/рулём (`LocationCalibrationEntryUi`). Ручные поля + дорожный набор, как у заправок.

### 7.1 Hard-iron 2D (стоянка)

Медленный круг, 1–2 оборота. Сбор `hx,hy` → центр окружности `(cx,cy)`. Покрытие 360° — по интегралу гиро ГУ.

`H' = H − hardIron`. Soft-iron (эллипс) — не в v1.

### 7.2 Смещение к GNSS в движении

Тот же контур, что `DriveCalibrationSession`: **сырой GNSS + CAN**, без тени.

Прямые (не дуги):

- CAN ≥ ~20 км/ч;
- только вперёд (задняя — пауза);
- малые `|yaw|` и `|steer|`;
- правдивый фикс, без скачка курса (`COURSE_JUMP_*`).

`yawOffset = wrap(GNSS_COG − magHeading_after_hardiron)`

В offset: склонение + разворот модуля + остаток hard-iron в heading. Отдельный WMM не нужен, если цель — истинный курс тени.

Готовность: достаточно окон на разных азимутах, σ offset меньше порога (~3°).

Фон (later, как online yaw scale): подкручивать только `yawOffset` при живом GNSS, debounce ~2 мин. Hard-iron фоном не трогать.

### 7.3 Истинный курс на ГУ

```text
trueHeading = wrap(atan2(hy', hx') + yawOffset)
```

после hard-iron. `t:mag.heading` — сырой магнитный; калиброванный считается на ГУ (чтобы превью калибровки не зависело от ESP).

## 8. DR (фаза 3)

Компас — **абсолютный** азимут. Не третья ветка дельт в `applyHeadingDelta` (гиро/руль дают Δ за шаг).

Новые значения `MockHeadingSource`:

| Источник | Поведение |
|----------|-----------|
| `COMPASS` | нос := калиброванный mag; лёгкий LPF. Простой режим |
| `GYRO_COMPASS` | интеграл гиро как сейчас + complementary к компасу, τ ≈ 10–20 с. **Основной полезный режим** |

Гиро / руль / гиро+руль без изменений.

На стопе гейт по-прежнему не крутит точку гиро/рулём. Для компаса: **подтянуть нос к mag, точку не двигать** (старт DR после простоя без GNSS).

Отбрасывать сэмпл:

- `|H|` далеко от калиброванного `fs` (динамик, ток, эстакада);
- `|Δmag|` за шаг ≫ `|Δgyro|` (магнитный удар);
- `ok=false` / нет свежего `t:mag` (старше ~1 с);
- `hello.mag=false`.

Гиро ГУ остаётся ВЧ источником. Второй IMU на компаньоне не нужен.

Констрейнт `constrainHeadingToTravel` (bicycle) для `COMPASS` / `GYRO_COMPASS` — тот же, что для гиро: не крутить нос сильнее, чем позволяют метры шага.

Geo-debug: `headingSrc=COMPASS|GYRO_COMPASS`, поля `mag.hx/hy/hz`, `mag.heading`, `mag.true`, `mag.fs`, `mag.ok`, `magChip`.

## 10. Тесты

**Юнит (без железа):**

- parse `hello` с/без mag (старый fw);
- `encodeMagChipSet` / parse `magChip` / `t:mag`;
- hard-iron fit (синтетический круг);
- GNSS-offset на прямых (как `DriveCalibrationMathTest`);
- `MockHeadingSource.fromStorage` + `usesGyro` / `usesCompass`;
- complementary blend и гейт на стопе (`MockLocationJobTest` / `SteerHeadingIntegratorTest` style);
- отбраковка по `|H|` и устаревшему mag.

**На железе (не в cloud VM):** RM3100 I2CEN=HIGH; смена пункта меню; MMC5983 если есть; круг на площадке; прямая ≥20 км/ч; тоннель vs чистый гиро.

## 11. Фазы внедрения

### Фаза 1 — шина, меню, телеметрия (этот контур, без DR)

Прошивка I2C + оба драйвера, NVS default RM3100, `hello`/`t:mag`/`magChipSet`, вкладка «Компаньон», тесты протокола, доки компаньона.

Критерий: на ГУ виден курс модуля, смена RM3100↔MMC5983 переживает reboot ESP, без чипа DR не меняется.

### Фаза 2 — калибровка

Окно hard-iron + GNSS-offset, ручные поля, сохранение. Превью `trueHeading` на «Геопозиция» / «Компаньон».

### Фаза 3 — источники курса DR

`COMPASS` и `GYRO_COMPASS`, гейт на стопе, geo-debug, полевые заезды.

### Later (не блокирует 1–3)

- Soft-iron 2D.
- Tilt-compensation (аксель на кабеле).
- Фоновый `yawOffset`.
- Команда ориентации осей.
- UM982 dual-antenna heading как ещё один абсолютный источник (без магнитометра, бесполезен в тоннеле).

---

## 12. Вне скоупа v1

- SPI для RM3100.
- BNO085 / ICM-20948 / QMC5883L.
- Хранение калибровки на ESP.
- Автовыбор чипа без меню (меню + `magSeen` достаточно).
- Суммирование гиро+руль+компас в один источник (слишком много гибридов; гиро+компас покрывает якорь, руль уже в GYRO_STEER).
