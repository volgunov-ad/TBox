# Пилот: ограничения скорости ФГИС СКДФ для Нижегородской области

Офлайн-обогащение дорожного пакета `ru-nizhny-novgorod` сведениями о скорости из [общедоступных данных ФГИС СКДФ](https://xn--d1aluo.xn--p1ai/service-api/public-data). **APK и runtime не менять:** приложение уже читает `maxspeed` из `.tboxroads`. Перед публикацией пакет проходит отчёт качества; неоднозначные сопоставления остаются с данными OSM.

Связанные docs: [TBOXROADS_FORMAT_RU.md](TBOXROADS_FORMAT_RU.md), [ROAD_MAPS_HOSTING_RU.md](ROAD_MAPS_HOSTING_RU.md).

---

## Статус

Не начато. Пилот — только субъект **Нижегородская область** (`ru-nizhny-novgorod`).

| 3 | Overlay в сборке `ru-nizhny-novgorod`, Python-тесты |
| 4 | Docs сборки карт, условия использования API, пилотный отчёт |

## Подход

- Отдельный сборочный модуль `tools/skdf_speed_limits.py`: получить набор `speed-limits` через read API ФГИС СКДФ (токен только из env или локального файла), загрузить публичные геометрии участков и координаты километровых знаков, нормализовать пикетаж и EPSG:3857 → WGS84.
- По километровым знакам построить монотонную привязку `км+м → координата`; границы интервалов скорости интерполировать между соседними знаками. Официальные линии сопоставлять с OSM-рёбрами по `ref`, расстоянию, направлению и доле перекрытия. Неоднозначные и низкоуверенные совпадения пропускать.
- Overlay в `tools/osm_to_tboxroads.py` **до** `build_payload`. Дополнительно резать OSM-ребро **только** в местах смены лимита СКДФ и только если **оба** получившихся куска ≥ **200 м**. Короткие остатки не создавать: сдвиг зоны ближе 200 м к началу/концу ребра (или к соседней оставленной точке разреза) поглощается соседней зоной. Ребро короче 200 м не режется вовсе. На неразрезанном куске берётся лимит с наибольшим перекрытием; при равном — меньший км/ч. Существующие разрезы по перекрёсткам OSM не трогать. Сохранить `wayId`/топологию и записать подтверждённый лимит в `maxspeed`, `maxspeedForward`, `maxspeedBackward`. Без совпадения оставлять текущий OSM-лимит.
- Опциональный этап в `tools/build_road_map_packs.py` для `ru-nizhny-novgorod` **до** `tile_whole_pack()`: тайлинг копирует рёбра как есть и не должен знать про СКДФ. Секреты не писать в репозиторий или пакет. Сборка должна уметь работать из сохранённого snapshot JSON для воспроизводимости и не падать без СКДФ, если overlay явно не запрошен.
- Для опубликованного пилота поднять `graphVersion` пакета `ru-nizhny-novgorod` (сейчас 4 → 5), чтобы UI показал «Обновить». `format` тайла остаётся `1`.

## Контроль качества

- Рядом с пилотным bundle — JSON-отчёт: число официальных интервалов, покрытые километры/OSM-рёбра, расхождения OSM↔СКДФ, пропущенные и неоднозначные участки, число разрезов, отклонённых из‑за порога 200 м, максимальная ошибка привязки к километровым знакам.
- Консервативные пороги: fail пилотной сборки при немонотонном пикетаже, чрезмерном расстоянии до OSM или низком покрытии. Точные значения закрепить синтетическими тестами и первым отчётом Нижегородской области.
- Расширить `tools/test_osm_to_tboxroads.py` и добавить тесты клиента/привязки СКДФ: парсинг, CRS, интерполяция, разворот линии, разрезание ребра при кусках ≥ 200 м, отказ от разреза при куске < 200 м, поглощение короткого хвоста, приоритет источника, неоднозначная параллельная дорога, snapshot без сети. Обновить `tools/test_build_road_map_packs.py` для CLI и отчёта.

## Совместимость и документация

- **APK не менять.** Kotlin/UI/`strings.xml`/загрузчик остаются как есть: `RoadGraph` уже читает `maxspeed`/`maxspeedForward`/`maxspeedBackward`, lookahead и виджет «Ограничение по карте» работают на этих полях. После публикации ZIP с `graphVersion` 5 установленный пакет обновляется без новой сборки приложения.
- Побочный эффект без правок кода: заполненные `maxspeed` попадут в `RoadMatchRoadProfile` (`>= 80` → highway). SLA/TSR (`SlaSpeedLimitDomain`) не затрагивается. Описание виджета в UI по-прежнему говорит «OSM» — это сознательно оставляем.
- Обновить только docs сборки (`TBOXROADS_FORMAT_RU.md`, `ROAD_MAPS_HOSTING_RU.md`): приоритет СКДФ → OSM, порог 200 м на overlay-разрез, команда пилотной сборки, snapshot/токен, метрики отчёта и атрибуция.
- До публикации обогащённого ZIP отдельно подтвердить, что условия API ФГИС СКДФ разрешают переработку и распространение данных внутри офлайн-пакетов; при запрете оставить интеграцию как локальный эксперимент без публикации.

## Источник (ФГИС СКДФ)

Проверено на портале общедоступных данных:

- Набор `speed-limits` (id 1010): интервалы с `start`/`finish` (пикетаж `км+м`), `speed_limit`, `design_speed`.
- Массовый `POST /service-api-go/api/v1/developer/dataset/export` требует read-токен ВИС (`X-External-System-Token`); без токена 403. Токен не класть в репозиторий.
- Публично без токена доступны карточка дороги, интервалы участка (`/api/v3/portal/hwm/passports/parts/{id}/speed-limits`), геометрия (`/api-pg/rpc/f_get_object_geom`, `object_type=901`, EPSG:3857) и километровые знаки с WGS84.
