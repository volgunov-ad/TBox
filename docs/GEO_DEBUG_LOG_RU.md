# Журнал geo-debug (вкладка «Геопозиция»)

Кратко: файл пишется раз в секунду с вкладки **Геопозиция** → блок журнала geo-debug. Каждый блок `---` — один снимок состояния. Файл обычно лежит в **Downloads**: `tbox_geo_debug_ГГГГММДД_ЧЧММСС.txt`, длительность записи до ~20 минут.

Код записи: `GeoDebugLogRecorder` (`app/src/main/java/vad/dashing/tbox/location/GeoDebugLogRecorder.kt`).

---

## Шапка и хвост файла

| Запись | Смысл |
|--------|--------|
| `# tbox geo debug log` | Это geo-debug журнал TBox Monitor |
| `# started=…` | Когда начали запись (время телефона/ГУ) |
| `# maxDurationMin=20` | Автостоп через 20 минут |
| `# stopped=… auto=… ticks=…` | Когда остановили; `auto=true` — по таймеру; `ticks` — сколько секундных снимков |

---

## Разделитель тика

Пример: `--- 2026-08-05 07:16:05.123 elapsedMs=123456 ---`

- время на часах устройства;
- `elapsedMs` — внутренние миллисекунды с загрузки Android (для стыковки событий, не «время суток»).

---

## Общие настройки (`source=…`)

| Поле | Смысл |
|------|--------|
| **source** | Откуда GNSS: `TBOX` / `USB` / `ESP32` / `ANDROID` |
| **mockOn** | Включена ли подмена геопозиции в систему (`true`/`false`) |
| **mockMode** | Режим подмены: `NONE` = Прямой, `WHEN_FIX_LOST` = При потере, `ALWAYS` = Всегда, `CONSTANT` = Продвинутый |
| **bitrate_bps** | Скорость входящих GNSS-данных (бит/с); `-` если не считается |

---

## Сырой приёмник (`gnss.…`)

То, что **сейчас пришло с GPS**, ещё до «украшательств» подмены.

| Поле | Смысл |
|------|--------|
| **fix** | Есть ли фикс (`true`/`false`) |
| **truth** | Внутренний флаг «правдивости» потока TBox (служебный, рядом с displayTruth) |
| **displayTruth** | То, что в UI как «правдива»: доверяем ли точке (фикс + координаты + фильтр мусора) |
| **lat / lon / alt** | Широта, долгота, высота |
| **speedKmh** | Скорость с приёмника, км/ч |
| **course** | Курс по земле (куда едет), градусы; на стоянке часто «крутится» — это шум GNSS |
| **mag** | Магнитный курс (если есть) |
| **sats** | `видимые/используемые` спутники |
| **hdop / pdop / vdop** | «Размытость» геометрии спутников; меньше — лучше; `-` если нет |
| **hrms / vrms** | Оценка ошибки в метрах (из GST и т.п.), если приёмник отдаёт |
| **fixQ** | Качество фикса (код NMEA GGA), если есть |
| **diffAge** | Возраст дифференциальных поправок (сек), RTK/DGPS |
| **accuracyM** | Оценка горизонтальной точности в метрах, как считает приложение |
| **gnss.raw=…** | Последняя «сырая» строка/дамп источника (для отладки), обрезана |

---

## Скорость с машины (`can.…`)

| Поле | Смысл |
|------|--------|
| **accountingKmh** | Скорость, которой пользуется учёт поездок / подмена (основная) |
| **huKmh** | Скорость с шины головного устройства |
| **telemetryKmh** | Скорость из телеметрии приложения |
| `-` | В этот момент значения нет |

На стоянке обычно ~0. Если CAN есть, а GNSS «ползёт» — для курса в режимах улучшения приложение опирается на CAN.

## Что уходит в навигацию / на экран (`mock.…`)

То, что видит подмена и виджеты (стрелка и т.д.).

| Поле | Смысл |
|------|--------|
| **lat / lon / alt** | Координаты, которые показываем / пишем в систему |
| **speedKmh** | Скорость на выходе |
| **speedSrc** | Откуда скорость: `GNSS` / `CAN` / `RETENTION` (удержание) |
| **bearing** | Курс на выходе (`-` если нет) |
| **bearingSrc** | Откуда курс: `GNSS` / `HELD` (заморожен на стоянке) / `RETENTION` (удержание/дорисовка) |
| **liveUsable** | Считаем ли живой GNSS пригодным для опоры прямо сейчас |
| **retaining** | Режим удержания последней хорошей точки (`true` = «синяя стрелка» удержания) |
| **locate** | Есть ли «фикс» на выходе подмены |
| **mockActive** | Подмена реально пишет в систему |
| **indicator** | Цвет/состояние стрелки: `LIVE` / `RETAINING` / `LOST` / `NONE` и т.п. |

**Как читать:** сравнивайте `gnss.lat/lon/course` и `mock.lat/lon/bearing`. Если GNSS пропал, а mock ещё едет — это удержание/дорисовка. Если на стоянке `gnss.course` крутится, а `mock.bearing` стоит и `bearingSrc=HELD` — удержание курса в режимах улучшения работает (в режиме **Прямой** курс может оставаться «как с приёмника»).

## Только режим «Продвинутый» (`constant.…`)

Строка есть, когда режим Advanced / тень активна (`mockMode=CONSTANT` или тень уже считается).

| Поле | Смысл |
|------|--------|
| **shadowDistM** | На сколько метров «тень» (расчётный путь) уехала от GNSS |
| **thresholdM** | Порог «это уже большое расхождение» (м) |
| **posW** | Вес подмеса GNSS в тень (0 = почти не слушаем GNSS, 1 = почти полностью GNSS) |
| **hasOrigin** | Тень уже заведена (есть стартовая точка) |
| **blendLive** | Идёт ли мягкий подмес живого GNSS |
| **hardResync** | Был ли жёсткий перезахват тени на GNSS в этом тике |
| **accuracyM** | Точность GNSS, использованная в расчёте тени |

Большой `shadowDistM` + маленький `posW` ≈ тень ушла далеко, GNSS почти не подмешивается. `hardResync=true` — тень принудительно вернули к GNSS.

Свежесть GNSS: если `bitrate_bps=0` / `nmea.tick=(none)` несколько секунд подряд, а `gnss.fix` ещё `true` с теми же lat/lon — это застывший `LocValues`. После правок приложение считает такой фикс протухшим (~3 с) и не soft-blend’ит его в Advanced; USB DETACH сбрасывает точку сразу.

## Угол руля (`steering.…`)

| Поле | Смысл |
|------|--------|
| **angleDeg** | Угол поворота руля с активного HU CAN backend, градусы; `-` если недоступен |
| **backend** | `Android9MbCan` / `Android10Vhal` |

На Android 9 запись журнала временно запрашивает `eMBCAN_VEHICLE_STEERING_ANGLE`
на всё время записи (subscribe + push `onSteeringWheel` + pull). На Android 10/VHAL — `MCU_REPLY_STEERING_WHEEL_ANGLE`
(**557845548**, ° as-is); скорость вращения руля на A10 недоступна.
Значение пока только записывается для оценки и не участвует в калибровке или DR.

## Онлайн-подстройка yaw (`online.…`)

В режиме **Продвинутый** при доверенном GNSS приложение понемногу подстраивает bias на прямых и **scale L/R** на поворотах (без бокового ускорения). То же — в режимах **Всегда** / **При потере**, пока GNSS правдив (запас на будущий DR). Изменения пишутся в Settings (debounce ~2 мин) и видны в меню **«Сохранённые калибровки»**. Поля лога: `yawScaleL` / `yawScaleR`, `lastScaleSide=L|R`, `biasTempC`. Online-дуга держится через краткие провалы `|yaw|<1.5` до ~2 с и закрывается от ~18° ∫ (не только непрерывные 25°). Scale-кандидаты с дуги отбрасываются при |ΔT| на сегменте > ~1.5 °C.

| Поле | Смысл |
|------|--------|
| **phase** | `IDLE` / `STRAIGHT` / `TURN` |
| **straightHoldMs** | Сколько уже держится «прямая» перед шагом bias |
| **turnGyroAbsDeg** | Накопленный \|∫gyro\| текущего поворота |
| **lastBiasStep** | Последний шаг bias (°/с), `-` если не было |
| **lastScaleCand** | Последний кандидат scale с дуги, `-` если не было |

---

## Задний ход (`reverse.…`)

| Поле | Смысл |
|------|--------|
| **huSwitch** | Концевик/сигнал задней с ГУ (после inverted decode) |
| **huPrnd** | Положение селектора с ГУ (P/R/N/D…) — **первый** источник для DR |
| **tboxPrnd** | То же с TBox — только если HU PRND неизвестен и switch не engaged |
| **consider** | Включена ли опция «Учитывать заднюю передачу» |

DR/mock: опция «Учитывать заднюю передачу» + `VehicleGearDomain.isReverseEngaged(huSwitch, huPrnd, tboxPrnd)` — при известном не-`R` на HU концевик игнорируется (АКПП); на МКПП без PRND решает switch. В режиме «Прямой» задняя не применяется.

В дорисовке при выключенной опции источники всё равно пишутся в лог.

## Сырые NMEA за эту секунду (`nmea.…`)

| Запись | Смысл |
|--------|--------|
| `nmea.tick=(none)` | За секунду не поймали NMEA-строк |
| `nmea.tick.count=N` | Сколько строк |
| `nmea|$GNRMC,…` | Сама NMEA (RMC — фикс/скорость/курс, GGA — координаты/спутники, GSA — DOP, GST — RMS, ZDA — время…) |

В RMC статус `A`/`V`: данные валидны / невалидны. Много `V` и нулевые координаты = пропал приём.

## Как быстро «прочитать поездку»

1. Смотрите **mockMode** и **mockOn** — какой режим реально крутился.
2. Сравните **gnss.*** и **mock.*** — расхождение = подмена / удержание / тень.
3. На стоянке: крутящийся **gnss.course** при стабильном **mock.bearing** и `bearingSrc=HELD` — норма для режимов улучшения.
4. В Advanced смотрите **constant.shadowDistM** / **posW** / **hardResync**.
5. Дыры GNSS — **fix=false**, `nmea` с `V`, нули в lat/lon.
6. Онлайн-калибровка yaw — **online.phase** / **lastBiasStep** / **lastScaleCand**.

### Скрипт разбора

```bash
python3 tools/geo_debug_analyze.py ~/Downloads/tbox_geo_debug_YYYYMMDD_HHMMSS.txt
python3 tools/geo_debug_analyze.py log1.txt log2.txt --csv /tmp/ticks.csv --json-summary /tmp/sum.json
```

Только стандартная библиотека Python. Печатает сводку: окна без truth, shadow peaks, hardResync, PRND, online bias/scale, оценка scale влево/вправо по дугам, провалы bitrate. Опционально CSV по тикам и JSON-сводка.
