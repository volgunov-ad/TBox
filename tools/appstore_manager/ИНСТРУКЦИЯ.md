# Менеджер каталога Dashing Store (Windows)

Мини-программа для наполнения sync-папки AppStore на Яндекс.Диске
(зеркало — Mail.ru). Пишет те же файлы, что читает APK `:store`.

## Что нужно

- Windows
- Python 3 с **tkinter** (сборки с [python.org](https://www.python.org/downloads/) —
  галочка «tcl/tk» при установке)
- Локальная папка, которую клиент Диска синхронизирует с
  [AppStore на Яндексе](https://disk.yandex.ru/d/KDaHLxbFtPAjYA)
  (желательно то же дерево копировать на
  [Mail.ru](https://cloud.mail.ru/public/voi3/4Lx1RhqV9))

Зависимостей `pip` нет.

## Запуск

Дважды щёлкнуть `Запуск.cmd` в этой папке  
или:

```bat
py -3 tools\appstore_manager\appstore_manager.py
```

## Как пользоваться

1. **Папка AppStore…** — указать корень sync (внутри должны быть
   `release\` и `dev\`, либо сразу `release\apps`).
2. Выбрать канал **release** / **dev**.
3. Слева — список приложений; справа — описание и версия APK.
4. **Сохранить описание** — пишет `catalog.meta.json` и пересобирает
   `catalog.json`.
5. **Заменить APK…** — копирует `.apk` в `apps\<id>\`, спрашивает **flavor**
   (`ru` / `en` / `default`; из имени файла часто угадывается `-ru-` / `-en-`),
   сам читает из APK: `packageName` / `versionCode` / `versionName` / label,
   **cert SHA-256** и по возможности **иконку**. В `version.json` запись этого
   flavor обновляется, APK другого языка **сохраняются** (можно держать оба
   ru и en). Если pin подписи уже был и ключ другой — подтверждение смены.
6. **Иконка…** — ручная замена PNG/WebP/JPEG (если из APK не извлеклось или
   нужна своя). В магазине на ГУ: иконка с Диска, иначе иконка установленного
   приложения, иначе буква названия.
7. **Добавить…** — выберите APK: подставятся package / version / title;
   id можно поправить. Без APK — только описание.
8. Клиент Яндекс.Диска сам унесёт изменения в облако; для Mail.ru —
   скопируйте то же дерево `release\apps` / `dev\apps`.

### Что такое cert SHA-256

Белый список отпечатков подписи в `catalog.json`. На ГУ Store после
скачивания сверяет сертификат APK с этим списком: несовпадение → отказ.
Пустой список = проверка подписи выключена (остаются sha256 файла и
packageName). Менеджер при замене APK **заполняет pin сам**; смена ключа
(другой cert) — только после подтверждения.

Чтение APK: `aapt` / `apksigner` из Android SDK при наличии, иначе разбор
`AndroidManifest.xml` + `keytool` для cert (stdlib / JDK, без pip).

При первом открытии пустой папки подставляется образец
`catalog.meta.json` из репозитория (**Dashing Store**, Monitor, MQTT, camd,
**DCL Launcher** и **DCL Install**). Если `catalog.meta.json` уже есть, но
в нём нет новых seed-id (например `tbox-store`), менеджер **дописывает**
их, не затирая ваши поля.

### Телефонное приложение (`phone`, installMode=phone)

Карточка `phone` (`vad.dashing.tbox.phone`) с `installMode=phone` в meta:
на ГУ **не** ставится. В магазине — QR на публичную страницу APK (Яндекс /
Mail.ru share) и кнопка «Скачать в Загрузки». В форме менеджера поле
`installMode` = `phone`.

### Самообновление магазина (`tbox-store`)

Карточка `tbox-store` (`vad.dashing.store`) — обычная запись каталога.
На ГУ Store сравнивает свой `versionCode` с каталогом: при обновлении
показывает баннер «Обновить магазин» и кнопку на карточке; «Открыть» /
«Удалить» для себя скрыты.

Публикация новой версии Store:

1. Собрать `./gradlew :store:assembleRuRelease` и
   `:store:assembleEnRelease` (или debug).
2. В менеджере выбрать `tbox-store` → **Заменить APK…** для `ru`, затем
   для `en` (flavor угадывается из имени `tbox-store-…-ru-….apk`).
3. Сохранить описание при необходимости → дождаться sync Яндекса и
   скопировать дерево на Mail.ru.

У DCL Install в поле «APK в Загрузки» стоит `dcl-launcher`: магазин при
скачивании установщика дополнительно кладёт APK лаунчера в
`/sdcard/Download`, чтобы выбрать его в DCLInstall. Сам лаунчер
обновляется отдельной карточкой без DCLInstall.

## Раскладка на диске

```text
AppStore/
  release/apps/
    catalog.meta.json
    catalog.json          ← собирает программа
    mqtt/
      version.json
      tbox-mqtt-….apk
    …
  dev/apps/
    …
```

CLI без GUI (из корня репо):

```bat
python tools\build_apps_catalog.py --apps-dir D:\YandexDisk\AppStore\release\apps --write
```

Подробности формата: [docs/APP_STORE_PLAN_RU.md](../../docs/APP_STORE_PLAN_RU.md).
