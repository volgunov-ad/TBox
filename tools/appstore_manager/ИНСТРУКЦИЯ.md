# Менеджер каталога TBox Store (Windows)

Мини-программа для наполнения sync-папки AppStore на Яндекс.Диске
(зеркало — Mail.ru). Пишет те же файлы, что читает APK `:store`.

## Что нужно

- Windows
- Python 3 с **tkinter** (сборки с [python.org](https://www.python.org/downloads/) —
  галочка «tcl/tk» при установке)
- Локальная папка, которую клиент Диска синхронизирует с
  [AppStore на Яндексе](https://disk.yandex.ru/d/KDaHLxbFtPAjYA)
  (желательно то же дерево копировать на
  [Mail.ru](https://cloud.mail.ru/public/voi3/4Lx1RhqV9))

Зависимостей `pip` нет.

## Запуск

Дважды щёлкнуть `Запуск.cmd` в этой папке  
или:

```bat
py -3 tools\appstore_manager\appstore_manager.py
```

## Как пользоваться

1. **Папка AppStore…** — указать корень sync (внутри должны быть
   `release\` и `dev\`, либо сразу `release\apps`).
2. Выбрать канал **release** / **dev**.
3. Слева — список приложений; справа — описание и версия APK.
4. **Сохранить описание** — пишет `catalog.meta.json` и пересобирает
   `catalog.json`.
5. **Заменить APK…** — копирует `.apk` в `apps\<id>\`, сам читает из
   манифеста APK `packageName` / `versionCode` / `versionName` (и label при
   необходимости), считает sha256, обновляет `version.json`. Поля версии в
   форме только для просмотра. Старые apk в папке приложения удаляются.
6. **Иконка…** — PNG/WebP/JPEG → `apps\<id>\icon.png` (или webp/jpg); в
   `catalog.json` появится поле `icon`. В магазине на ГУ: иконка с Диска,
   иначе иконка уже установленного приложения, иначе буква названия.
7. **Добавить…** — выберите APK: подставятся package / version / title
   (label); id можно поправить вручную. Без APK — только описание.
8. Клиент Яндекс.Диска сам унесёт изменения в облако; для Mail.ru —
   скопируйте то же дерево `release\apps` / `dev\apps`.

Чтение манифеста: если в системе есть Android SDK (`aapt` / `ANDROID_HOME`),
используется `aapt dump badging`; иначе — разбор `AndroidManifest.xml` внутри
APK (stdlib, без pip).

При первом открытии пустой папки подставляется образец
`catalog.meta.json` из репозитория (Monitor, MQTT, camd, **DCL Launcher**
и **DCL Install**). У DCL Install в поле
«APK в Загрузки» стоит `dcl-launcher`: магазин при скачивании установщика
дополнительно кладёт APK лаунчера в `/sdcard/Download`, чтобы выбрать его
в DCLInstall. Сам лаунчер обновляется отдельной карточкой без DCLInstall.

## Раскладка на диске

```text
AppStore/
  release/apps/
    catalog.meta.json
    catalog.json          ← собирает программа
    mqtt/
      version.json
      tbox-mqtt-….apk
    …
  dev/apps/
    …
```

CLI без GUI (из корня репо):

```bat
python tools\build_apps_catalog.py --apps-dir D:\YandexDisk\AppStore\release\apps --write
```
