# Флешки NTFS и exFAT при скрытом System UI на ГУ A9

Нужно, только если System UI скрыт (`pm hide com.android.systemui`), как в [инструкции по плавающей кнопке и шторке](../blank_wallpaper/ИНСТРУКЦИЯ.md). Без этого шага флешка есть в системе, но программы её не видят, а «Файловый менеджер +» пишет, что NTFS и exFAT не поддерживаются.

Причина не в файловой системе. Служба `vold` не смотрит внешние диски, пока ей не сообщат, что экран блокировки снят. Это делает System UI. Разблокировку делают два механизма, держать оба не нужно:

- **DCL-лаунчер `ras.dashing.tbox.launcher` 0.8.2+ (основной).** Делает unlock сам при каждой загрузке — быстрее и без лишних пакетов. Этот APK (`UsbMount.apk`) устанавливать не нужно, а если он уже стоит — удалить (см. «Переход на встроенный unlock»).
- **Этот пакет `UsbMount.apk` (запасной).** Для стендов без DCL-лаунчера или со старым лаунчером (< 0.8.2). Делает тот же вызов при каждой загрузке и System UI не показывает.

## Если стоит DCL-лаунчер 0.8.2+

Ничего ставить не нужно. Проверка после загрузки:

```
adb shell sm list-volumes all
```

В списке должна быть строка `public:… mounted` (том появляется на ~+24-й секунде загрузки). Результат unlock-вызова лаунчера: `/data/local/tmp/unlockusb_boot.txt`.

Если раньше ставился этот пакет — удалить его, иначе он дублирует unlock. Для лаунчера старше 0.8.2 бут-фиксап `dcl_install` снимает с уже установленного пакета пометку «не запускался» (`Unstop`), но заново пакет не ставит. У лаунчера 0.8.2 и новее этого шага нет: в журнале будет только `WARN usbmount_present`, пока пакет не удалён.

```
adb uninstall vad.dashing.usbmount
```

## Установка запасного пакета (старый лаунчер / без DCL)

Из этой папки, ГУ доступно по ADB (адрес подставьте свой):

```
adb connect 192.168.1.128:5555
adb install -r UsbMount.apk
adb reboot
```

После загрузки флешка появляется в `/storage/…` (маунт ~+50 с). Значок у программы нет, удалять её не нужно.

Проверка, что том смонтирован:

```
adb shell sm list-volumes all
```

В списке должна быть строка `public:… mounted`.

Повторно вызвать монтирование без перезагрузки:

```
adb shell am broadcast --include-stopped-packages -n vad.dashing.usbmount/.BootReceiver -a vad.dashing.usbmount.ARM
```

## Важно

- Запросы разрешений на USB-устройство (не флешка, а адаптер или телефон) по-прежнему не появляются: их окно находится в System UI (это не чинит ни лаунчер, ни этот пакет).
- `pm unhide com.android.systemui` возвращает штатное поведение; после этого разблокировка не нужна, и пакет можно удалить: `adb uninstall vad.dashing.usbmount`.
- Наблюдения по вариантам unlock и хронометраж — §10.4 [HEAD_UNITS_DEVICE_NOTES_RU.md](../../docs/HEAD_UNITS_DEVICE_NOTES_RU.md).
