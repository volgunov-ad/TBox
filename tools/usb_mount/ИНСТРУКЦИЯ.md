# Флешки NTFS и exFAT при скрытом System UI на ГУ A9

Нужно, только если System UI скрыт (`pm hide com.android.systemui`), как в [инструкции по плавающей кнопке и шторке](../blank_wallpaper/ИНСТРУКЦИЯ.md). Без этого шага флешка есть в системе, но программы её не видят, а «Файловый менеджер +» пишет, что NTFS и exFAT не поддерживаются.

Причина не в файловой системе. Служба `vold` не смотрит внешние диски, пока ей не сообщат, что экран блокировки снят. Это делает System UI. Пакет `UsbMount.apk` делает тот же вызов при каждой загрузке и System UI не показывает.

## Шаги

Из этой папки, ГУ доступно по ADB (адрес подставьте свой):

```
adb connect 192.168.1.128:5555
adb install -r UsbMount.apk
adb reboot
```

После загрузки флешка появляется в `/storage/…`. Значок у программы нет, удалять её не нужно.

Проверка, что том смонтирован:

```
adb shell sm list-volumes all
```

В списке должна быть строка `public:… mounted`.

Повторно вызвать монтирование без перезагрузки:

```
adb shell am broadcast --include-stopped-packages -n vad.dashing.usbmount/.BootReceiver -a vad.dashing.usbmount.ARM
```

## Важно

- Запросы разрешений на USB-устройство (не флешка, а адаптер или телефон) по-прежнему не появляются: их окно находится в System UI.
- `pm unhide com.android.systemui` возвращает штатное поведение, пакет можно удалить: `adb uninstall vad.dashing.usbmount`.
