# Убрать штатную плавающую кнопку и шторку на ГУ A9 без долгой загрузки

Для ГУ **A9** (mbCAN) со сторонним лаунчером. После этих шагов пропадают штатная плавающая кнопка «Домой» и шторка, выдвигающаяся сверху. ГУ загружается так же быстро, как раньше (даже немного быстрее).

Почему просто отключить System UI нельзя: штатные обои находятся внутри System UI. Без них система при каждой загрузке ждёт обои 30 секунд. Программа «Пустые обои» (`BlankWallpaper.apk`) подставляет свои обои, и ожидания нет. Подробности и замеры: [docs/SYSTEMUI_A9_DISABLE_RU.md](../../docs/SYSTEMUI_A9_DISABLE_RU.md).

## Что понадобится

- ПК с `adb` (Android platform-tools).
- ГУ в той же Wi-Fi-сети, что и ПК, с включённым ADB по сети (порт 5555). Ниже адрес ГУ — `192.168.1.128`, подставьте свой.
- Файл `BlankWallpaper.apk` из этой папки.

## Шаги

1. Подключиться к ГУ:

   ```
   adb connect 192.168.1.128:5555
   ```

2. Установить «Пустые обои»:

   ```
   adb install -r BlankWallpaper.apk
   ```

3. Открыть окно установки обоев:

   ```
   adb shell am start -a android.service.wallpaper.CHANGE_LIVE_WALLPAPER --ecn android.service.wallpaper.extra.LIVE_WALLPAPER_COMPONENT vad.dashing.blankwallpaper/.BlankWallpaperService
   ```

   На экране ГУ нажать **«Установить фоновый рисунок»** (справа вверху), затем выбрать **«Главный экран и экран блокировки»**.

   Проверка — в ответе должно быть `vad.dashing.blankwallpaper`:

   ```
   adb shell dumpsys wallpaper | findstr mWallpaperComponent
   ```

4. Скрыть System UI:

   ```
   adb shell pm hide com.android.systemui
   ```

   Именно `pm hide`. Команда `pm disable-user` на этой прошивке не работает: после перезагрузки System UI включается снова.

5. Перезагрузить ГУ:

   ```
   adb reboot
   ```

После загрузки плавающей кнопки и шторки нет, лаунчер выглядит как раньше.

## Важно

- **Не удаляйте «Пустые обои» и не меняйте обои**, пока System UI скрыт, иначе вернётся загрузка с задержкой ~30 секунд.
- Вместе с System UI пропадают: быстрые настройки шторки (Wi-Fi, Bluetooth, яркость, громкость), уведомления, всплывающий индикатор громкости, меню питания и системные запросы разрешений (например, доступ приложения к USB-устройству).
- После сброса до заводских настроек шаги нужно повторить.

## Как вернуть всё обратно

```
adb shell pm unhide com.android.systemui
adb reboot
```

По желанию после этого можно выбрать штатные обои и удалить программу: `adb uninstall vad.dashing.blankwallpaper`.

## Если нужна только штатная шторка без плавающей кнопки

System UI не скрывать (шаги 2–5 не нужны), а выполнить:

```
adb shell appops set com.android.systemui SYSTEM_ALERT_WINDOW ignore
```

Кнопка пропадает сразу. Вернуть: то же с `default` вместо `ignore`. Сохраняется ли это после перезагрузки, пока не проверено.
