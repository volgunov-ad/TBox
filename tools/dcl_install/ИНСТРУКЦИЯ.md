# Установка DCL на головное устройство A9

Программа **«Установка DCL»** ставит лаунчер Dashing Club Launcher и сама делает то, что иначе приходится вводить командами: разрешения, скрытие System UI и штатного лаунчера, флешки и обои. В конце головное устройство перезагружается.

Нужно устройство **A9 mbCAN**. На другой прошивке кнопка установки не работает.

## Откуда берётся APK DCL

Файл лаунчера **внутрь установщика не вшит**. Его выбирают на экране: внутренняя память (`/sdcard`) или флешка (`/storage/…`). Подойдёт, например, `DCLv077ru.apk`.

Программа принимает только пакет `ras.dashing.tbox.launcher`. Другой APK она не поставит.

В самой программе уже лежат три вещи, их отдельно класть не нужно: программа для флешек, картинка обоев по умолчанию и средство включить обои без кнопки на экране.

## Что сделать один раз

Поставить программу на головное устройство. С компьютера, ГУ в той же сети:

```
adb connect 192.168.1.128:5555
adb install -r DclInstall.apk
```

Адрес подставьте свой. Пока System UI ещё штатный, тот же APK можно открыть с флешки через файловый менеджер.

Положите APK лаунчера на флешку или во внутреннюю память.

## Установка

1. Откройте **Установка DCL**. Сверху список: зелёным отмечено то, что уже есть, красным — чего не хватает для работы лаунчера. Ниже, в «По желанию», серым показано то, что скрывать не обязательно.
2. Нажмите **Выбрать APK** и укажите файл лаунчера.
3. Обои. Штатные обои находятся внутри System UI. Когда он скрыт, без своих обоев каждое включение ждёт около 30 секунд. Картинка видна в конце загрузки, пока лаунчер не нарисовал свой экран, и там, где окно не закрывает фон.
   - **Картинка по умолчанию** — уже внутри программы;
   - **Чёрный фон**;
   - **Своя картинка** — jpg или png, кнопка **Выбрать картинку**.
4. Галочки. Сразу отмечены **System UI** и **IoT Tube**. System UI — это плавающая кнопка «Домой» и шторка. Голосовой помощник, клиент голоса и электронное руководство скрываются, только если их отметить. Снятая галочка уже скрытый пакет не возвращает.
5. Нажмите **Установить и перезагрузить**.

Если на устройстве уже стоит DCL с другой подписью, программа спросит: удалить старый и поставить новый или остановиться. При удалении настройки лаунчера стираются. TBox Monitor это не затрагивает.

Дальше ничего нажимать не нужно. Устройство само перезагрузится. После загрузки кнопка HOME открывает DCL. Если была отмечена галочка System UI, плавающей кнопки и шторки нет, а флешка NTFS или exFAT видна программам.

Если установка оборвалась, текст ошибки на экране. Тот же журнал лежит в `/sdcard/dcl_install_log.txt`.

## Что пропадёт

Вместе со штатным лаунчером пропадает его рабочий стол с карточками: карта, музыка, климат и ADAS внутри этого стола. Климат, настройки автомобиля, телефон, камера, радио и TBox Monitor остаются.

Вместе с System UI пропадают шторка, плавающая кнопка «Домой», уведомления, всплывающая громкость и системные вопросы вроде доступа программы к USB-устройству. Флешки при этом монтируются: для этого установщик ставит отдельную маленькую программу.

Сброс к заводским настройкам снимает скрытие и обои. Установку нужно повторить.

Вернуть скрытый пакет:

```
adb shell pm unhide имя.пакета
adb reboot
```

Штатный лаунчер — `com.wt.launcher3`, System UI — `com.android.systemui`.

## Как работает программа

Кнопка **Установить и перезагрузить** делает шаги по порядку.

1. Читает выбранный файл и проверяет, что это `ras.dashing.tbox.launcher`. Сравнивает подпись с уже установленным DCL. Совпадает — ставит поверх. Не совпадает — спрашивает, удалять ли старый.
2. Записывает выбранные обои в свою защищённую память. Она доступна ещё до входа в систему, поэтому при скрытом System UI загрузка не ждёт окно обоев 30 секунд.
3. Кладёт на `/sdcard` короткий сценарий и просит системную службу `mb_daemon` выполнить его от root. Обычному приложению эти команды недоступны.
4. Сценарий ставит выбранный APK командой `pm install` прямо с того места, где файл лежит. Копировать его в установщик не нужно.
5. Выдаёт разрешения и настройки лаунчера.
6. Закрепляет DCL домашним экраном.
7. Ставит программу флешек `vad.dashing.usbmount`.
8. Включает обои установщика без подтверждения на экране.
9. Включает штатный лаунчер и сразу скрывает его (`pm enable`, затем `pm hide`). Одного выключения недостаточно: это постоянный пакет, и его процесс после перезагрузки всё равно стартует. Скрытый пакет не стартует.
10. По галочке скрывает System UI. Галочка включена сразу.
11. По галочкам скрывает IoT Tube, голосовой помощник, клиент голоса и электронное руководство.
12. Перезагружает устройство. Скрытие постоянных пакетов начинает действовать только после перезагрузки.

Разрешения и настройки, которые выдаются всегда:

| Команда | Зачем |
|---|---|
| геолокация и доступ к памяти | поездки и файлы лаунчера |
| поверх других окон, изменение настроек, установка пакетов | панели и обновление |
| `WRITE_SECURE_SETTINGS` | системные настройки |
| `MANAGE_ACTIVITY_STACKS`, `ACTIVITY_EMBEDDING` | окна приложений |
| `READ_LOGS` | журнал |
| `enable_freeform_support 1` | свободные окна |
| `policy_control immersive.full=*` | полный экран |
| доступ к уведомлениям | музыка и уведомления |
| служба специальных возможностей лаунчера | навигация лаунчера |

Служба специальных возможностей добавляется к уже включённым. Другие службы из списка не стираются.

При установке сами выдаются обычные разрешения файла: интернет, Wi‑Fi, Bluetooth, обои, автозапуск. Отдельно их включать не нужно.

`REAL_GET_TASKS`, `REORDER_TASKS` и автомобильные `android.car.permission.*` эта прошивка командой `pm grant` не выдаёт: это права подписи, их нельзя назначить установленному вручную приложению. Лаунчер на A9 ходит в машину через mbCAN, эти автомобильные права ему для этого не нужны.

Программа не трогает `com.mengbo.aiservice`, список приложений `com.android.launcherWT`, телефон, Bluetooth и TBox Monitor.
